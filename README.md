# Greece National Data Portal (data-gov-gr)

Greece National Data Portal is a open data portal open-data portal for gr running **CKAN**, exposing a standardized catalog API over ~21,931 datasets.

**URL:** [Visit APIs.json URL](https://raw.githubusercontent.com/api-evangelist/data-gov-gr/refs/heads/main/apis.yml)

**Run:** [Capabilities Using Naftiko](https://github.com/naftiko/fleet?utm_source=api-evangelist&utm_medium=readme&utm_campaign=data-gov-gr-api-evangelist&utm_content=repo)

## Type
- **kind:** government  ·  **software:** CKAN  ·  **version:** 2.11.3

## API
- **Greece National Data Portal CKAN Action API** — base `https://data.gov.gr/api/3/action`. [Docs](https://docs.ckan.org/en/latest/api/) · [Portal](https://data.gov.gr)
- Live endpoint verified: `https://data.gov.gr/api/3/action/status_show` · ~21,931 datasets
